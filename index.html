GitHub sync

Each document is saved as a plain-text file in a private GitHub repository. Your token is kept on this device only and is only sent to GitHub.

When your phone or browser offers to save the token as a password, say yes. Next time, tap the token box to fill it in.

How to make the token
  1. On github.com, open your picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it "Tallyline" and pick an expiry date.
  3. Under Repository access, choose Only select repositories and pick your private notes repository.
  4. Under Permissions, set Contents to Read and write. Nothing else is needed.
  5. Generate it, copy it, and paste it above. Keep a copy in your password manager, because GitHub only shows it once.
